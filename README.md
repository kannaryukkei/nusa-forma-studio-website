# Nusa Forma Studio — internal static concept

Fictional internal experiment. Nine static Indonesian routes. No backend, CMS, database, CRM, booking, payment, login, persistent form submission or external integrations.

## Local preview
Requires Python 3. From repository root: `python3 -m http.server 4173`, then open `http://localhost:4173/`. Stop with Ctrl+C. No dependency installation or build step is required.

The inquiry preparation UI only creates a summary in the current browser and provides copy-to-clipboard. It does not transmit or store data. Pages use `noindex,nofollow` while the project is an internal concept.

All diagrams are original synthetic SVG illustrations, not documentary project photography or evidence of completed work.
